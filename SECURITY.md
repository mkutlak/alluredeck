# Security Policy

## Supported versions

Only the latest release receives security fixes. The container images
(`ghcr.io/mkutlak/alluredeck-*`) and the Helm chart are built from it.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/mkutlak/alluredeck/security/advisories/new).
Do not open a public issue.

Include:

- the affected version or commit
- steps to reproduce, or a proof of concept
- the impact you observed

Reports are handled on a best-effort basis. You will be credited in the
advisory unless you ask not to be.
